**Prepared:** 21 October 2026. **Status:** Internal prequalification working document; not a completed tender declaration. Public repository version contains NO private IDs, statements, certificates or customer personal information.

## Evidence classification

- **REPO-EVIDENCED** = statement directly supported by current source code or public site copy, **not** necessarily deployed or proven in client delivery.
- **SELF-DESCRIBED** = public business positioning on site; must not be mistaken for formal business registry.
- **UNVERIFIED** = absence of evidence in the sources reviewed; neither a positive nor negative assertion about actual capability.
- **NOT SATISFIED** = only if documentary evidence affirmatively shows the requirement is not met (not currently established).
- **VERIFIED FOR TENDER** = requires legal/evidentiary review of actual documents and current tender terms.
